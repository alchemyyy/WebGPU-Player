generate_nis_wgsl.py converts NVScaler.glsl at a 32x16 block instead of the port's 32x24, so its shared memory fits WebGPU's default 16 KiB.
NVSharpen.glsl fits as it is and converts with tools/convert_mpv_shader.py directly.
Their outputs beside this folder are committed, so a build needs neither Python nor naga.
