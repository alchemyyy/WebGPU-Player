TrueHD and MLP capability fixture provenance

These files contain only deterministic, mathematically generated sine tones.
They contain no copied media content. tools/generate_truehd_capability_fixtures.py
encodes them with FFmpeg and embeds complete access units plus reference PCM
fingerprints in src/custom/TrueHDExactCapabilityFixtures.ts. Its
--check --regenerate-sources mode re-encodes the streams and fails unless they
match the committed bytes.

truehd_51_side_24_96000.mka is a deterministic, metadata-free Matroska remux of
the corresponding elementary stream and validates Mediabunny A_TRUEHD packet
extraction. The recorded remux command is:

  ffmpeg -fflags +bitexact -f truehd -i truehd_51_side_24_96000.truehd -c:a copy -f matroska truehd_51_side_24_96000.mka

Current FFmpeg builds write slightly different container bytes, so the
committed file is the reference.
